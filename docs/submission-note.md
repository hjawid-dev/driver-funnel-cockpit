# Prototype submission note

Driver Funnel Cockpit supports two users: Ops handling a pickup exception and applicants progressing to a completed first drive. Live Ops combines the incident facts, contact escalation, customer updates, an owned decision and preventive confirmations. The funnel combines a deadline queue, written checks, document reminders and self-booked matching first drives.

Ops works the full 48-calendar-hour registration-to-decision clock, including missing documents and exceptions to weekday review blocks. Booking is not activation: missed deliveries remain work, released reservations leave an unassigned customer transport, and confirmed replacements preserve first-drive tracking.

Four primary metrics cover mature-cohort conversion, document completion, mean decision time and first-drive activation. Acceptance, delivery outcomes and monthly throughput are supporting diagnostics. Weekly review chooses one blocker and one process change; no measured improvement is claimed from fictional demo actions.

This is a clickable prototype with simulated integrations, built with Claude Code and Codex. The brief names Lovable or Google AI Studio; acceptance of this different platform choice needs confirmation.
